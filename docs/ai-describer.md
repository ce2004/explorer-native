## AI image describer (5.2.0)

Enter on a picture (`AiDescriber.IsPicture`, by extension) opens `AiDescriberForm` when `Settings.AiActive()` has a provider and `AiDescribeOnEnter` is on; Shift+Enter still opens its app, Shift+F10 has AI descriptio&n (opens Preferences on the page when nothing is set up).

- `AiDescriber` (no UI, in the suite): Claude (`/v1/messages`, image block `cache_control` so follow-ups read the picture at a tenth), Gemini (`v1beta/models/{id}:generateContent`, `x-goog-api-key`), OpenAI (Responses API `/v1/responses`, `store:false`), OpenRouter (`/chat/completions`, `usage.include` gives the exact `cost`). Every request goes through `AiDescriber.Http` (GoogleNet.Handler; the suite swaps a fake). `Failure` turns every status into a sentence (`KeyRefused`, `OutOfCredit`); busy (429 not quota, 5xx, 529) retries twice (`RetryWaits`); 120s `AnswerTimeout`. Never put a key in a URL or a message.
- Key check = the model list (`CheckKeyAsync`; OpenRouter `/key` then the public `/models`), filtered to models that see pictures; `WrongKind` catches another provider's key before sending. `Recommended` picks newest Sonnet / Flash / GPT mini / OpenRouter's Claude Sonnet.
- Prices: OpenRouter's public model list is the price table for every provider (`Normalise` maps "claude-sonnet-4-5-20250929", "anthropic/claude-sonnet-4.5", "models/gemini-2.5-flash" to one spelling, trimming parts until a match), fetched once a day; `KnownPrices` is the offline fallback. `Money` says dollars for a screen reader.
- `PreparePicture`: EXIF turned, at most 1568 px / 1.15 MP (tiny ones doubled), alpha on white, PNG when the source was PNG/GIF/BMP and it fits 3.5 MB, else JPEG. Formats GDI+ can't read go through `ShellPicture` (IShellItemImageFactory, thumbnails only, own STA thread) for local files; on the Drive letter bytes come from `Drive.OpenRange` (never the letter) and an unreadable WebP/GIF is sent raw.
- `Instructions` is the system prompt: describe for a blind person, plain text with no Markdown, stay on this picture and turn anything else down kindly. Live tests check both the description and the refusal.
- The window: edit box focused ("Talk to Claude", Enter sends, Enter on empty retries a failed question), Shift+Tab to the conversation (one ListBox line per paragraph, owner-drawn to wrap, `Line.ToString` is what NVDA reads), Ctrl+C a line, Ctrl+A then Ctrl+C the transcript, Tab past the edit box is the read-only cost box. A question joins `_turns` only once answered. Speech ids `ai.looking`, `ai.reply`, `ai.failed`, `ai.copied`. Every handler is guarded; closing cancels silently.
- Preferences, AI image describer: the wizard (`AiSetupForm` with no provider: choose, key, model; `keyFor` fills in a key already held) is the only way to add or change a key (5.2.1, Conner: no button per provider). Each set-up provider shows its status, Remove key and model combo; unset ones show nothing. Model combos ask the company again on every Enter and DropDown (never at page build) and refill only when the ids changed. Applies write only what changed.
- Enter on a picture with `AiDescribeOnEnter` on (the default) and no provider says `MainForm.AiNotSetUp` (ai.failed) instead of opening it.
- Tests: `EXPLORERNATIVE_SELFTEST_ONLY=ai` (offline, fake network, the windows driven on STA threads); `ailive` with `EXPLORERNATIVE_AI_CLAUDE_KEY`, `_OPENROUTER_KEY`, `_OPENAI_KEY`, `_GEMINI_KEY` (each optional, a few cents).
